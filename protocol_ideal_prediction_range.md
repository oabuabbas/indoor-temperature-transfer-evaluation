# IDEAL development: temperature-filter prediction sensitivity

Post-result exploratory study designed after observing original IDEAL development results and quality range sensitivity. Never generate holdout forecasts; this is not preregistration or confirmation. Keep precisely the same 177 development-home sensor identities and source/validation assignments from `protocol_ideal_development_v1.md`. Reconstruct raw hourly data independently for 15–40°C and 10–45°C with the same 25 valid distinct readings per 10-minute slot, four slots per hour, equal valid-slot weights, UTC, and no imputation. Refit a separate source ridge for each filter on its eligible source-home rows before 2017-09-01; source identities remain fixed but an insufficient source home can differ across variants, which must be reported. Use the same source model features and penalty 100, 6-hour horizon and target and issue-time boundaries as v1.

For each existing development-validation house and monthly window, obtain separate candidate rows for each filter. Require >=24 prior-history examples in each variant, and >=24 **common test issue times**, where both variants have all features and the target. Train/select locally using the history from that same variant only, using persistence, prior-day baseline, frozen source ridge and 30-day past-label-based selector (ties persistence, daily, ridge). Include a local 30-day ridge as a comparison, not as a selector candidate. Score all methods for both variants on the exact same issue times per home-month; exclude home-month for all variants if the common test or either history requirement is not met. Histories and source training need not have identical rows between variants and their counts must be reported. Filters can change the aggregated target itself, even on the same issue time, so differences in MAE jointly reflect model inputs, target values, training data, and selection—not a causal estimate of the model alone. Report number and mean absolute difference of changed target-hour temperatures, equal-home MAE by variant, selection frequencies, group counts and per-home comparison. Do not infer population effects or claim testing the heldout set.
