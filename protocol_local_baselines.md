# Local nonlinear baselines and blocked temporal uncertainty

Exploratory analysis; this protocol was written after substantial prior examination of the same PLEIA holdout. It is not preregistered, a fresh independent test, or a valid basis for publication-level significance claims. Target is one PLEIA building; NEST source is one Swiss research platform. Sensors and rooms within a building are dependent. We evaluate h=6 hours chosen from prior exploratory outcomes; inputs and raw preparation as protocol_daily_residual.md, with no weather, no HVAC intervention, no imputation, range 15–40 C, >=4 observed slots/hour. Target timestamps used for labels; forecasts require input-hour start after the end of training/calibration respectively.

Jan 1–14 target fitting, Jan 15–30 target development (issue-hour start >= Jan 15), refit chosen target model on Jan 1–30 inclusive; Feb 1–28 interval calibration (issue-hour start >= Jan 31), March 1–Dec 17 test (issue-hour start >= March 1). Require >=24 fitting, development, calibration, and test records; methods on matched eligible sensors and hours. Features: current temperature, previous hour temperature, target-hour's previous-day temperature, hour sine/cosine. Models predict residual from daily reference. Baselines: persistence, previous-day reference, source-only ridge trained on NEST before Nov 2020; local ridge with regularization {1,100,1000} selected on January development; local histogram gradient boosting regressors with fixed learning_rate=.05, max_iter=70, min_samples_leaf=20, max_leaf_nodes in {7,15} and l2_regularization=10, selected by January development, refit on all January; implementation scikit-learn and recorded library versions. Fixed grids chosen after prior exploration; validation reuse across algorithms can overfit. No future weather or target leak is permitted.

Evaluate per-sensor MAE and 90% absolute-residual intervals calibrated separately on February; empirical coverage and width, with no coverage guarantee under temporal dependence or shift. Aggregate equally by sensor; matched points for all methods.

For a limited *conditional* sensitivity analysis of error differences, resample non-overlapping calendar weeks jointly across all sensors, preserving cross-sensor dependence at the sampled week level. Weekly summary stores abs-error sum and count per sensor/model. For each of 2,000 seeded draws, sample same number of weeks with replacement, form per-sensor weighted MAE from sampled sums/counts, average across sensors, compute model minus daily error. Report 2.5/97.5% empirical quantiles and fixed-sample effect; this is a descriptive calendar-week block bootstrap, not a valid confidence interval for new buildings or sites and may not capture seasonal nonstationarity or long temporal dependence. Missing sensors in bootstrap draws must be reported; no p-values or broad claims. Save per-sensor model choice, test counts, weekly aggregates, outcomes, interval results and package version. Data-filter and clock limitations from earlier protocols remain.
