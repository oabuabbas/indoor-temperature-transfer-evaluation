# Prospective risk-aware fallback, exploratory

Written before evaluating these gates but after extensive prior inspection of PLEIA and ORNL results. Not preregistered or confirmatory. Data, filtering and source models follow protocol_daily_residual.md. One source site NEST, one target building PLEIA; sensors/rooms are dependent. 1,6,24-hour forecasts. Source target timestamps precede 2020-11-01. Target fitting Jan 1–14 2021, gate choice Jan 15–30, residual interval calibration February, evaluation March–Dec 17. All validation forecast issue timestamps are >= Jan 15 and all test issue timestamps >= March 1; target timestamps remain inside their specified windows. Require >=24 cases in each fit, validation, calibration and evaluation block.

Train source ridge on NEST daily-reference residual; adapt coefficients using target fitting observations. Test policies: persistence, daily-reference, adapted residual, and a validation-selected gate. Candidates for the gate (1) always choose persistence, daily, or adapted; (2) choose one fallback among persistence/daily and use adapted only when one past-only score is at or below a threshold. Scores are |current temperature - last-hour temperature|, |current temperature - previous-day reference|, and absolute model correction. Candidate thresholds are validation-set quantiles 25%, 50%, 75%; all estimated using validation features. Search all candidates using validation MAE and deterministic order as tiebreak; this is multiple candidate selection on one period and may overfit, not a novel method claim. The same source model and target training, same observations, and fixed features are used. Scores are observable at the end of the current hour; no future target, outcome-defined bin, future weather or HVAC signal is used.

All models assessed on matched complete cases and nominal 90% symmetric intervals calibrated independently per sensor/policy in February and held fixed; report MAE, empirical coverage, width and proportion of gated decisions using adapted predictor. Identical candidate family/horizons chosen after preceding results, and finite calibration is not guaranteed under dependence or shift. Per-sensor equal weight mean and per-room counts; site, rooms and repeated measurements are not independent. Reporting is descriptive only, no significance or deployment claims. A more rigorous independent-site and prospective holdout and hyperparameter comparison remain necessary. Avoid exposure to PLEIA test targets when setting threshold, candidate policy or quantile.
