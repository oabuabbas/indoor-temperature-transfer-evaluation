# Secondary IDEAL holdout filter sensitivity

Defined **after** examining the locked primary holdout outcomes; exploratory, not a new untouched test or preregistration. Do not alter `protocol_ideal_holdout_v1.md` or its results and do not use this analysis to redefine its primary outcome. Fix the same 73 holdout sensor identities, same 55 development source houses where eligible, 6-hour horizon, features, ridge penalty, calendar windows and selector rules. Rebuild hourly readings independently under 10–45°C and 15–40°C using the primary ten-minute and hourly eligibility rules. The 15–40°C source ridge is separately trained from development-source homes with >=24 pre-cutoff samples; source-home set and row counts can differ and are to be reported. The 10–45°C source ridge is reproduced from the original training protocol.

In each target house-month, require >=24 historical examples for **each** filter and >=24 common test issue times where all features and target exist in both filters. For both filters score persistence, daily baseline, source ridge, 30-day local ridge and past-30-day rolling selector on the same common issue timestamps, with each filter's own previously observed history; selector candidates remain persistence, daily and source ridge. Do not add the tree model to the selector. The six-model primary table and its support are unchanged; this secondary comparison uses five methods and reduced support.

Raw aggregation can change the target itself, even at a common timestamp; record number and magnitude of target-value differences. Report equal-home MAE for each filter and method, number of houses, windows and observations, and selector decision changes; no p-values, no inference over geographic sites. Interpret as joint sensitivity of training rows, features, targets and history, not causal effect of temperature filter in isolation. Record method and cohort support consistency, source counts and exclusions. All historical outcomes and data used here derive from the same holdout already evaluated, so this is not a second independent test.
