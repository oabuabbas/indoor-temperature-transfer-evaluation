# Post-result exploratory local baseline on IDEAL development

Designed after inspecting `ideal_development_v1` results. Do not call this preregistered or confirmatory; do not compute holdout predictions. Reuse exactly the same selected development-validation houses, monthly windows, valid row sets and 6-hour temperature features from v1. For each already eligible house-month fit a separate ridge regression (penalty 100, standardization learned on that 30-day history only) predicting target temperature minus the prior-day reference, using the same historical issue/target eligibility as the existing selector. Predict the unchanged test rows with the local ridge plus previous-day reference. This baseline consumes local labels and is not zero-shot. It is added for comparison and is not a candidate in the already computed rolling selector. Do not retune penalty or choose candidate method using the test-period labels.

Assert the original selection/test counts match exactly. Append local error summaries to copies of original house-month results, keeping v1 outputs intact. Aggregate to equal-house mean MAE. Report within-house wins, ties and losses as descriptive only. The same-site house split, retrospective coverage-selected cohort, and earlier-protocol limitations remain.
