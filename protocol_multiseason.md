# NEST two-year seasonal pilot

Exploratory study; developed after inspecting earlier results and not a registered confirmatory evaluation. Input: July 2019 through June 2021, two annual files for each unit; file checksums verified against Figshare. Source training precedes 1 Nov 2020 and excludes target unit. Target adaptation uses target time 1–7 Nov; December is target-room calibration; test seasons are Jan–Mar and Apr–Jun 2021. A feature timestamp is one hour before its target timestamp; filtering is based on target time. Each annual file is resampled separately.

Features: last two observed hourly temperatures, current outdoor temperature, current solar irradiance, sine/cosine of hour. Target is the next hourly mean. Hours with fewer than 45 observed minutes are invalid. Identical complete-case test records are used for each model and scenario. No future weather, HVAC control or energy predictions are included. Because incomplete inputs are dropped before synthetic masking, results do not represent genuine outage windows or all hours. An entire sensor type is masked over each simulated scenario, replaced by training mean; no outage duration dynamics are modeled.

Baselines: persistence; pooled source ridge; source ridge adapted using target 7 days; target-only ridge trained on target 7 days. An exploratory masked-input model augments source data with ambient missing and solar missing, uses missing-indicator features, and replaces the masked standardized input with zero. Augmentation has three times as many training examples and changes effective ridge regularization; it is not an equal-compute or equal-regularization comparison. No target adaptation is used for the augmented model. It is a prototype, not a claim of novelty.

Uncertainty: per-model per-room December residuals give a nominal 90% finite-sample absolute residual interval. Intervals are calibrated on clean observed features and reused unchanged for sensor masking and subsequent seasons. Temporal dependence, season shift, shared site and training selection invalidate any assumption of guaranteed seasonal or conditional coverage. Rooms with fewer than 24 calibration observations are excluded, and zero-test seasons omitted.

Results use equal-weight means across eligible rooms; rooms in a common unit are not independent buildings. UMAR temp_276 has zero complete cases in calibration and both test seasons and is excluded, leaving 13 rooms in these results. Report per-room and per-season data, not an inflated effective sample size or causal conclusions. This experiment does not evaluate energy, control, deployment, or data from an independent location.

Correction applied after discovery: calibration input-hour start must be at or after December 1 (later than seven-day adaptation completion); test input-hour start must be at or after January 1 calibration end. Target timestamp must also remain within each period. Archived pre-correction outputs must not be used as final coverage results.
