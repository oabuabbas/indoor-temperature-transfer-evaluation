# ThermBuild follow-up sensitivity analysis

Exploratory follow-up designed after observing the original ThermBuild results; no statistical confirmation is claimed. Use the same source model, training data, features and primary 6-hour horizon as in `protocol_thermbuild.md`, with no target fitting or selection. Compare original target filter 15–40°C and a wider target filter 10–45°C inclusive, holding the source model fixed at the original 15–40°C training filter. Count raw nonmissing values and rejected values per room. Compare models within each filter on its own eligible support, and separately compare the two filters on the intersection of eligible issue times per room. The hourly values can differ even on common support because four-reading means are recomputed after filtering. Use identical evaluation rows for all models within each filter and support.

For temporal stability, divide the relative target-time grid into non-overlapping 60-day blocks beginning at ordinal hour 0. Group by forecast target hour, not issue time; final block is shorter. Report each house's equal-room average if every room has at least 24 eligible observations in that block, together with room-specific observation counts. Do not label blocks as calendar months or seasons. No bootstrap over rooms, no independence claims, no confidence intervals. Explore whether persistence beats transferred model at room level, since a single average hides variation. These checks do not validate the assumed 15-minute clock, data completeness, or deployment feasibility.
