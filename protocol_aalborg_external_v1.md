# Aalborg external fixed-model comparison v1

Locally fixed after examining source metadata, file structure/quality and results on prior datasets but BEFORE computing Aalborg forecast errors. The source dataset did not train the IDEAL-source ridge or choose the three-feature selector or the selected IDEAL nonlinear configuration. Not public preregistration, not an independent analyst or an untouched design: the research and model configurations were chosen after other-site results. Six correlated office rooms in one Aalborg University building are one external building/site, not six independent sites. No climate/population or causal/energy/control inference.

## Source and preparation
Source Melgaard et al., Zenodo v3 record 10673763, CC BY 4.0, `dataset__2023_02_27__2023_12_31.csv`, published MD5 `51b6528edbc2ccd0d78282a2e75668e1`, local SHA-256 `1c9b6197294e89da864cfac69e0d25165ed95da27a17c318518d0a0e010c5464`. Source file semicolon-delimited; read only timestamp and six columns `RoomA:Sensor__room_temperature` ... `RoomF:Sensor__room_temperature`. Source says BMS room measurements originally five minutes and were aligned by timestamp, not linearly interpolated; missing room measurements marked #N/A, while outside temperature was interpolated and is not used. Data preprocessing already performed by data authors. A source timestamp has an explicit UTC offset changing with Danish DST. Parse each into UTC before any resampling. Reject missing/malformed timestamps and count them. Stop on duplicate valid timestamps or time reversal; retain per-room missingness; numeric 10–45 C inclusive as analytic filter, do not label rejected points faulty. Floor to 5-min UTC bins and average distinct bins; form hourly mean if >=8 distinct valid 5-min bins, each bin equally weighted. No interpolation added. Report full-period quality and data availability. Hourly mean at hour t is only available after t+1h ends; future target at t+6 is an hourly mean and no network latency is measured. Processing differs from IDEAL and Bremen.

## Windows and models
Issue hours t in calendar months 2023-04-01 through 2024-01-01 UTC exclusive, with t+6h strictly before the following month boundary. No retrospective test-size inclusion filter; every eligible hour counts for input readiness. Models are past-only: the frozen source daily residual ridge was trained on 55 IDEAL development-source homes and 125,779 eligible rows with target before 2017-09-01. Verify selection and counts. For each room/month use preceding 30 days of complete feature+target rows with target-hour start strictly before month start; >=24 examples required for selector, local ridge and local boosting. Select persistence, daily or source with history MAE, tie order as earlier; selector requires full features t,t−1,t−18 even when chosen simpler. Fallback order selector, persistence, daily, abstain. Train local ridge and two fixed HGB configurations on exactly the same history, inputs, daily-residual target. `hgb_ideal_selected` is the shallow configuration from `ideal_nonlinear_tuning_v1_choice.json` (60 iterations, leaves5, leafmin40, l2=20, lr .05; early_stopping false, seed 20261029); verify frozen grid/protocol and selection hash, no Aalborg fitting of hyperparameters. `hgb_bolzano_fixed` uses prior Bolzano fixed configuration (100 iterations, leaves15, leafmin20, l2=1, lr .1, early_stopping false). Neither is a selector candidate. These are two fixed configurations, not a claim of optimal or state-of-the-art nonlinear performance. Each method including source, selector, fallback and two HGB versions is evaluated on the exact intersection of observed target and all eight predictions; no pooled or imputed future observations.

## Outcomes and integrity
Primary descriptive benchmark is equal-room mean MAE and equal-room mean RMSE on common support of eight methods; report per-room, monthly window counts and room-level wins/ties/losses against selector. For fallback vs persistence also report paired support, equal-room MAE and outcome counts on that different support; report own readiness from all opportunities, branches, availability and missing target counts separately. Choices, full per-issue predictions and summary hashes saved for auditing; refuse overwrites. No p-value, population CI or assertions of independent data points. Quality/coverage inspection can inform pre-declared analysis; no prior Aalborg forecast errors seen. Data authors and licence credited; user must independently check all source requirements before public release.
