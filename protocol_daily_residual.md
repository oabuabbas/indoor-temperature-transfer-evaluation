# Exploratory external seasonal-residual correction

Written before running this study, but after observing earlier NEST/PLEIA results; not preregistered or confirmatory. Source NEST data have target time < 2020-11-01; target PLEIA raw data are filtered/aggregated as in protocol_external_pleia.md. One target site only. No weather, intervention, control, or energy claims.

Hours 1, 6, 24. For each target room sensor use Jan 1–14 inclusive for model fitting; Jan 15–30 inclusive for selecting a blend; Feb 1–28 to calibrate uncertainty; March 1–Dec 17 for held-out evaluation. Periods apply to forecast target timestamp; additionally validation issue timestamps start Jan 15 and test issue timestamps start March 1, preventing later fit/calibration labels from being used for forecasts issued earlier. Inputs must be observed before the target and same-hour data are available only after the hour closes. Source vs target temporal cutoffs prevent source training reaching target fitting. Require at least 24 complete observations for each fit, blend selection, calibration, test; exclude sensor/model when insufficient. The same sensor set and same complete rows are used for methods within each horizon, period and scenario. Individual sensors are not independent buildings.

Daily baseline is the last observed hourly temperature corresponding to the same target clock time one day earlier, using issue-time index t+ h-24, a non-future value for h <= 24. Models predict target minus this daily baseline, with observed input values current temperature, previous hourly temperature, daily baseline, and local-hour sine/cosine. Source ridge is trained on pooled NEST training rows, with source-only standardization and fixed penalty. Target ridge uses target first 14 days only, target-specific standardization. Adaptation fits residual ridge toward source coefficients on target first 14 days (fixed penalty). Source covariates and targets must pass the same 15–40 °C range; no future weather. For time resampling PLEIA requires 4 of 6 observed 10-minute bins, NEST 45 of 60 minute observations; differences are limitations.

Blend predicts `daily + w * adapted_residual`; w chosen separately per sensor/horizon from {0,0.25,0.5,0.75,1} by MAE on Jan 15–30 only, ties to smaller w. Compare raw daily, current persistence, source residual, adapted residual, target-only residual, selected blend; all use identical cases. Calibration absolute residual 90% finite-sample order statistic on February; report empirical Mar–Dec coverage and mean width. No claimed coverage guarantee under serial dependence, selection and seasonal shift. Compare equal-weight sensor means and wins; sensors within one site are dependent. This method is a prototype and not claimed novel; after earlier analyses significance and performance generality remain unresolved.

Post-hoc diagnostic added after initial results: stratify completed test cases by absolute observed change `|target - current|` into <0.5, 0.5–1, 1–2, >=2 °C. This uses target outcomes and cannot be used as an online decision variable. Report per-sensor bins only when >=24 cases; eligible sensor sets differ between bins. The bins do not isolate causality or intervention effects.
