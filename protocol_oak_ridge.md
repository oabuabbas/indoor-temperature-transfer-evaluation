# Exploratory third-site NEST → Oak Ridge test

Fixed after locating the Figshare metadata, file names, first/last dates and room-column labels but before computing ORNL forecasting outcomes. Not preregistered or confirmatory; prior NEST and PLEIA results already observed. Dataset authors Yoon et al., doi:10.1038/s41597-022-01858-6; dataset doi:10.6084/m9.figshare.20520438.v3, CC BY 4.0. Source NEST as in protocol_daily_residual.md. Third site ORNL is one unoccupied commercial test building with 10 rooms. Seven HVAC operating scenarios are short, noncontinuous episodes of roughly 5–8 days. Rooms and episodes are not independent sites or samples. Do not compare directly to occupied, year-long PLEIA as if conditions match.

Source NEST training target timestamp < 2020-11-01, earlier than all ORNL episodes. Fit a source-only ridge residual model per horizon, same `nest_source` and `fit` as daily_residual.py; inputs observed indoor current and prior hourly temperature, the matching previous-day target-time temperature, and local hour sine/cosine. Three prediction methods: persistence, previous-day same-target-hour baseline, source-only residual. 1, 6, 24 hour horizons, no future temperature, HVAC setpoints, weather, target fitting, calibration or hyperparameter tuning. No uncertainty-coverage results claimed. Source target range filter 15–40 C and target same. Target files include a unit row that must be excluded; their timestamps are treated as documented local wall-time but offset/timezone is not established. We use only their hour of day; no cross-site timestamp join, and no claim of timestamp alignment to weather. Each episode analyzed separately to avoid bridging gaps.

For each room and episode, resample minute-level temperatures to hourly means only if >=45 valid minute samples; discard duplicate minutes completely and invalid dates; no temperature imputation. For each horizon, require input current/prior/daily and target observed, minimum 24 valid test examples, all methods matched on same rows. Hours at beginning/end of episode unavailable by definition. Output per room, case and horizon; aggregate equally across rooms and scenarios explicitly. Report exclusions and available rows; avoid pooled sample significance and claims of site generalization, HVAC or energy performance. Preserve file sizes and hashes. Any subsequent sensitivity study is separately labeled.
