# Exploratory weather-clock sensitivity for cross-site forecasting

Post-hoc pilot, not preregistered; prior temperature and weather clock diagnostics already inspected. Source NEST before Nov 2020, target PLEIA from Feb to Dec 17 2021, January target only for interval calibration. One target building. Two competing unverified interpretations of raw station clock: UTC and Europe/Madrid civil time. Ambiguous and nonexistent Madrid timestamps are excluded, not guessed. Data under both hypotheses use the same source model and only samples observed under both hypotheses. This does not establish the true weather clock.

Target indoor sensor hourly means: raw measurements range 15–40 C, four observed 10-min slots, no imputation. Weather tmed [-40,60] C and radmed [0,1500] W/m² are averaged by 10-minute UTC slots and then hour, requiring four slots. The weather value supplied for input hour t is from hour t−1, for both source and target, as a one-hour conservative lag. This avoids use of readings in the future input hour under common interval label conventions but does not establish station aggregation label or data latency. NEST weather values are similarly averaged, requiring 45 of 60 raw minute readings and lagged one hour. Weather forecasts and future HVAC actions are not used; not a control model.

Horizon 1,6,24 hours. NEST feature history: indoor current/previous hourly means, local hour sine/cosine, lagged weather ambient and solar. Train two ridge residual-to-current models on exactly same NEST complete rows, one with weather, one without. Use source scaling only and fixed ridge penalties. PLEIA sensor timestamps parse explicit offsets to UTC, local hour via Europe/Madrid. Generate per-sensor common timestamps for both time hypotheses and no-weather model before splitting. Test methods: persistence, source-no-weather, source-weather assuming UTC and source-weather assuming Madrid. Absolute residual symmetric intervals calibrated for each sensor/model/horizon using January; for test input-hour start >=Feb 1 and test target in Feb–Dec 17. >=24 matched calibration and test rows per sensor/horizon. No tuning from target labels, but interval calibration uses target labels. Report MAE, coverage, width and matched case count; equal sensor weights, no claims of independent sites, guaranteed coverage or overall superiority. Excluded cases and changes in sensor eligibility may affect interpretation.
